Professional Python

Master Python in depth. Understand how it works. Write production-grade code.

See more topics covered
  • How Python really works: CPython, bytecode, everything is an object, names vs references, mutability, identity vs equality, reference counting and garbage collection
  • Data structures in depth: list, tuple, dict, set internals and Big-O cost, slicing, unpacking, shallow vs deep copy, collections (deque, defaultdict, Counter, namedtuple)
  • Functions like a pro: *args/**kwargs, keyword-only args, mutable default pitfall, LEGB scope, closures, decorators, functools (wraps, partial, lru_cache)
  • Iteration: iterator protocol, generators, yield from, lazy evaluation, itertools, comprehensions vs generator expressions
  • Object-oriented design: classes, properties, class/static methods, inheritance and MRO, composition over inheritance, abstract base classes, dataclasses
  • Python data model: dunder methods (__repr__, __eq__, __hash__, __len__, __iter__, __enter__), operator overloading, writing Pythonic classes
  • Errors and resources: exception hierarchy, custom exceptions, EAFP style, context managers and contextlib
  • Type safety: type hints, Optional/Union, generics, TypedDict, Protocols, static checking with mypy (strict mode), runtime validation with Pydantic
  • Modules and packaging: how imports work, __main__, project layout, virtual environments, pip, pyproject.toml
  • Files and data: pathlib, text encodings, JSON, CSV, working with real-world data
  • Concurrency: the GIL, threading vs multiprocessing, asyncio and async/await basics
  • Testing and debugging: pytest, fixtures, mocking, pdb debugger, logging instead of print
  • Code quality and performance: PEP 8, ruff/black, profiling with cProfile and timeit, writing readable code
  • Capstone project: build a tested, packaged command-line application end to end

Django Web Development

Build web apps. Create APIs. Ship real projects.

See more topics covered
  • How Django works: request/response cycle, MVT architecture, settings, URL routing, apps vs projects, the development server
  • Models and the ORM: fields, relationships (ForeignKey, ManyToMany, OneToOne), migrations, QuerySets, lookups, aggregation, select_related/prefetch_related and avoiding N+1 queries
  • Views and templates: function-based vs class-based views, generic views, template language, inheritance, static and media files
  • Forms and validation: Form and ModelForm, validation, CSRF protection, file uploads
  • Authentication and permissions: users, login/logout, custom user model, groups, permissions, protecting views
  • Django admin: registering models, customizing list views, filters, search and inline editing
  • REST APIs with Django REST Framework: serializers, viewsets, routers, pagination, filtering, token/JWT authentication, API permissions
  • Databases in production: PostgreSQL setup, indexes, transactions, data migrations
  • Middleware, signals and background tasks: custom middleware, signals, caching, Celery with Redis for async jobs
  • Testing: Django test client, pytest-django, factories, testing views and APIs
  • Security: XSS, CSRF, SQL injection, secure settings, environment variables and secrets
  • Deployment: Gunicorn, Nginx, Docker, collectstatic, deploying to a cloud server
  • Capstone project: build and deploy a full web app with a REST API end to end

Machine Learning with Python

Use Python for data, models, and AI thinking.

See more topics covered
  • Math foundations: linear algebra (vectors, matrices), probability, statistics and calculus intuition for ML
  • NumPy: arrays, broadcasting, vectorization, indexing and fast numeric computing
  • Pandas: DataFrames, cleaning messy data, missing values, groupby, merge/join, reshaping
  • Data visualization: Matplotlib and Seaborn, exploratory data analysis (EDA), telling stories with charts
  • Supervised learning: linear and logistic regression, k-NN, decision trees, random forests, gradient boosting (XGBoost)
  • Unsupervised learning: k-means, hierarchical clustering, PCA and dimensionality reduction
  • Model evaluation: train/test split, cross-validation, accuracy, precision, recall, F1, ROC-AUC, bias vs variance, overfitting
  • Feature engineering: scaling, encoding categorical data, feature selection, scikit-learn pipelines
  • Tuning: hyperparameter search with GridSearchCV and RandomizedSearchCV, regularization
  • Deep learning basics: neural networks, backpropagation, activation functions, building models with PyTorch
  • Applied AI: intro to NLP, computer vision, embeddings and working with LLM APIs
  • Deploying models: saving models, serving predictions with a FastAPI endpoint
  • Capstone project: solve a real dataset problem from raw data to deployed model
